# Молодь.Діє — локальний прототип

Навчальний прототип цифрової екосистеми короткострокових завдань і можливостей для молоді на основі наукової роботи МАН «МОЛОДЬ.ДІЄ: РОЗРОБЛЕННЯ МОДЕЛІ ЦИФРОВОЇ ЕКОСИСТЕМИ БЕЗПЕЧНОЇ КОРОТКОСТРОКОВОЇ ЗАЙНЯТОСТІ МОЛОДІ В УКРАЇНІ» (Харків, 2026).

## Запуск

Потрібен Node.js 18 або новіший. У корені проєкту виконайте:

У Windows запустіть файл `Запустить сайт.bat`: він відкриє вікно сервера на порту 3001 і браузер із сайтом.

Для GitHub Pages використовується статична збірка `npm run build` у `dist/`. Workflow `.github/workflows/pages.yml` публікує її після кожного push у `main`. GitHub Pages не запускає `server.js`, тому серверні API, зокрема реєстрація та вхід, там недоступні.

```sh
npm start
```

Якщо `npm` недоступний у PATH, запустіть напряму:

```sh
node server.js
```

Відкрийте http://localhost:3000. Сервер слухає лише `127.0.0.1`. Зупинка — `Ctrl+C`. Додаткові пакети, облікові записи та зовнішні сервіси не потрібні.

## Що працює

- адаптивні сторінки каталогу, пошуку, можливостей, навчання, анкети, опису й безпеки;
- серверні фільтри за запитом, напрямом, віком і форматом;
- деталі оголошення, локальні збережені картки, демо-відгук, звернення та подання оголошення;
- анкета з 25 запитаннями, серверна перевірка кількості відповідей та локальне збереження;
- навчальні матеріали й синтетичні демонстраційні оголошення;
- збереження заявок, оголошень, звернень та анкет у `data/demo.json`.

Усі профілі та завдання демонстраційні. Паролі, документи, банківські реквізити не збираються. Авторизація, модераторська черга, погодження батьків/опікунів, перевірка особи через «Дію», безпечна угода й переказ коштів не підключені. Статус віку в оголошенні не є юридичним допуском. Сертифікати не видаються. Відгуки та скарги лишаються локальними й не надсилаються реальному замовнику.

## Технології та файли

Node.js HTTP server без сторонніх залежностей, HTML, CSS, JavaScript та JSON-файл як локальне демонстраційне сховище. `server.js` містить API й синтетичні початкові оголошення; `app.js` — інтерфейс; `styles.css` — стилі; `data/demo.json` створюється під час першого запуску. Наданий користувачем логотип розміщено у `logo.jpg`.

## Джерела й точність

Використано DOCX і зображення логотипа, передані разом із завданням, та вимоги з `Molod_Die_Codex_Mega_Prompt.md`. Анкета присутня в науковій роботі, але документ не містить підтвердженого масиву відповідей. Застосунок не показує вигаданих результатів як дослідження. Детальні нотатки: `docs/product-brief.md`, `docs/research-notes.md`.

Це прототип для локальної демонстрації, а не чинна платформа працевлаштування, перевірки безпеки або юридична консультація. Перед пілотом потрібні юридичний аналіз актуальних норм України, реальна автентифікація та контроль доступу, захищена база даних, незалежна безпекова оцінка, модерація, політики приватності й належно інтегровані партнери.

## Авторизація прототипу

Реєстрація запитує ім’я, прізвище, email, пароль і його повтор. Сервер перевіряє збіг паролів, хешує пароль через scrypt і вимагає підтвердити адресу перед входом. Локальна версія не надсилає листи: після реєстрації на екрані є демонстраційна кнопка підтвердження. Для справжніх листів потрібен поштовий провайдер і його SMTP/API-доступ. Вхід «через Дію» — лише позначений фіктивний сценарій: з’єднання з Дією немає, особу та вік він не підтверджує. Сесії зберігаються в локальному JSON-файлі й діють сім днів.
